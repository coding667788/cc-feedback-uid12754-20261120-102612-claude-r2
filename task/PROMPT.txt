实现完全离线的通信接收端模拟器。只有合成的报文元数据、模拟认证结果与本地 SQLite，没有网络监听。每条会话在建立时固定租户、连接代数和首个已知绝对序号。报文携带 16 位循环序号、连接代数、密钥代数和数据摘要。服务端从当前期望序号两侧仅在 128 项窗口内恢复唯一绝对序号，窗口左边界用于核查历史回执，右边界之外拒绝；序号恰在半圈处不得推断。旧新密钥可同时有效，但允许区间以绝对序号限定且同一序号最多接收一次。

合成报文可乱序到达并持久缓存，只连续释放到队列；每个绝对序号的首次接收记录必须绑定摘要和密钥证据。授权撤销只让该代仍未交付的数据失效并为其写显式空位，已经交付的历史不撤销。合法推进必须以事务内版本为准。用独立写进程对比同一序号从两密钥同时入队、前序缺失后撤权、65535 到 0 的交接、旧连接号重用、失效认证无入队。

在乱序报文已保存但提交未完、队列推进已提交但未回复两处终止自己的工作进程，重启重放并核对有序交付、拒绝原因、持久收据及无重复。用独立定长窗口参考回放覆盖随机合成序列和完整前后边界。

在 Windows 原生 Python 3.12、标准库和 CPU 环境下实现，全部输入自行合成，离线测试。交付源码、README、可重放 cases.json 和自动化测试。提供 python -m solution --input cases.json --output result.json 与 python -m unittest discover -s tests -v。测试须断言具体结果，README 写明规则、输入输出、错误码和实测结果。
